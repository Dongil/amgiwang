## 1. Overview

### 1.1 Purpose

학교에서 사용하는 **Word Master 고등 Complete** 영어 단어장 PDF를 파싱하여 암기왕 앱의 vocab_cards DB에 자동으로 임포트한다. 기존 수동 카드 생성 대신, PDF 한 번 업로드로 **DAY 1~30 전체 단어**(약 900+개)를 구조화된 데이터로 변환한다.

### 1.2 Background

- 대상 PDF: `data/Word Master 고등 Complete_본책.pdf` (408페이지)
- 이 단어장은 DAY 단위(1~30)로 구성, 각 DAY에 약 30개 단어 수록
- 기존 앱의 vocab_cards 테이블과 **유사하지만 다른 구조**를 가짐
- 특히 **Collocation**(연어), **파생어**, **유의어/반의어 기호 체계**가 기존과 다름

### 1.3 Word Master 단어장 구조 분석

#### PDF에서 추출한 단어 항목 구조

```
0001 evidence                          ← 4자리 번호 + 단어
n 증거, 흔적 v 입증하다, 증거가 되다   ← 복수 품사/뜻 (n/v/a/ad)
Evidence shows that global warming... ← 영어 예문
지구 온난화가 분명히...               ← 한국어 해석
+ good[clear/strong] evidence         ← Collocation (+ 기호)
  훌륭한[명확한/강력한] 증거
= helpful a 도움이 되는               ← 유의어 (= 기호)
↔ guilty a 유죄의                     ← 반의어 (↔ 기호, PDF에서 공백으로 표시)
  evident    a   분명한, 눈에 띄는     ← 파생어 (탭 들여쓰기)
  evidence   n   증거                  ← 파생어 계속
```

#### 기호 체계 (기존 앱과 차이점)

| 기호 | Word Master 의미 | 기존 앱 매핑 |
|------|------------------|-------------|
| `=` | 유의어 (synonym) | `meanings[].synonyms[]` |
| `↔` / 공백 앞 반의어 | 반의어 (antonym) | `antonyms[]` |
| `+` | Collocation (연어) | **신규 필드 필요** |
| 탭 들여쓰기 | 파생어 (derivative) | `derivatives[]` |
| `수능` / `교과서` | 출제 소스 태그 | **신규 필드 필요** |
| `n` `v` `a` `ad` | 품사 약어 | `meanings[].pos` |

#### Collocation 특수 구조

Word Master의 핵심 차별점. 단어와 자주 쓰이는 어구를 수능/교과서 출처와 함께 제시:
```
natural ingredient   천연 재료
artificial ingredient 인공 재료
key ingredient       핵심 성분    수능
main ingredient      주요 성분    교과서
basic ingredient     기본 요소    수능
```

### 3.2 DB 마이그레이션 (006_wordmaster_fields.sql)

```sql
-- vocab_cards 신규 필드
ALTER TABLE vocab_cards
  ADD COLUMN IF NOT EXISTS collocations JSONB DEFAULT '[]',
  ADD COLUMN IF NOT EXISTS word_number INT,
  ADD COLUMN IF NOT EXISTS day_number INT,
  ADD COLUMN IF NOT EXISTS source_book TEXT;

-- collocations JSONB 구조:
-- [{ "phrase": "key ingredient", "meaning": "핵심 성분", "source": "수능" }]

-- 인덱스
CREATE INDEX IF NOT EXISTS idx_vocab_cards_day_number ON vocab_cards(day_number);
CREATE INDEX IF NOT EXISTS idx_vocab_cards_source_book ON vocab_cards(source_book);
```

## 4. 파싱 전략

### 4.1 PDF 텍스트 → 구조화 데이터 변환 파이프라인

```
PDF (408p)
  ↓ pdf-parse v1 텍스트 추출
전체 텍스트
  ↓ DAY 경계 분할 (regex: /DAY\n(\d{2})/)
DAY별 텍스트 블록 [30개]
  ↓ 단어 항목 분할 (regex: /(\d{4})\s+(\w+)\n/)
단어별 텍스트 블록 [~900개]
  ↓ 필드 파싱 (품사/뜻, 예문, 유의어, 반의어, Collocation, 파생어)
VocabCard[] 구조화 데이터
  ↓ 미리보기 + 사용자 확인
DB INSERT (batch)
```

### 4.2 파싱 규칙

| 패턴 | Regex / 로직 | 추출 필드 |
|------|-------------|----------|
| 단어 번호 + 단어 | `/^(\d{4})\s+([a-zA-Z\s-]+)$/m` | word_number, word |
| 품사 + 뜻 | `/^(n\|v\|a\|ad)\s+(.+)$/` (복수 품사 분리) | meanings[] |
| 예문 (영어) | 대문자로 시작하는 영어 문장 | example_sentence |
| 예문 (한국어) | 한글로 시작하는 줄 | example_translation |
| 유의어 | `/^=\s+(.+)\s+(n\|v\|a\|ad)\s+(.+)/` | meanings[].synonyms |
| 반의어 | `/^↔?\s*(.+)\s+(n\|v\|a\|ad)\s+(.+)/` | antonyms[] |
| Collocation | `/^\+?\s*(.+?)\s{2,}(.+)/` + 수능/교과서 태그 | collocations[] |
| 파생어 | `/^\t(.+?)\s+(n\|v\|a\|ad)\s+(.+)/` | derivatives[] |

### 4.3 임포트 옵션

| 옵션 | 설명 |
|------|------|
| **단일 덱** | "Word Master 고등 Complete" 덱 1개, day_number 필드로 DAY 구분 |
| **DAY별 덱** | DAY 01 ~ DAY 30 각각 별도 덱 (30개) |
