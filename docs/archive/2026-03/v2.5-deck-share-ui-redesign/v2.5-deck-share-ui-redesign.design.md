### 1.4 컴포넌트 스타일 변경

**Button** (shadcn/ui CSS 변수로 자동 적용)
- Primary: 에메랄드 그린 배경, 화이트 텍스트
- `rounded-xl` (CSS 변수 `--radius: 0.75rem`으로 자동)
- 최소 높이 48px (터치 타겟, `min-h-[48px]`)

**Card**
- `rounded-2xl` (기본 radius 증가로 자동 확대)
- 미세한 보더 + 약간의 섀도우: `shadow-sm`
- 카드 배경: 순백 (`--card: white`)

**Input/Textarea**
- 포커스 시 에메랄드 링: `focus-visible:ring-primary`
- placeholder 색상: `--muted-foreground`

**Badge**
- 기본: 연한 민트 배경 + 그린 텍스트 (secondary variant)

**Progress**
- 바 색상: `--primary` (에메랄드)

## 3. API 설계

### 3.1 공유 설정 API

**`PUT /api/decks/[id]/share`**

```typescript
// Request
{
  share_mode: "none" | "public" | "private"
}

// Response 200
{
  share_mode: "public",
  share_id: "abc123xyz"  // public일 때 생성
}
```

- 인증 필수 (middleware)
- 본인 덱만 변경 가능 (RLS)
- `share_mode = 'public'` 시 `share_id` 자동 생성 (없으면 nanoid(12))
- `share_mode = 'none'` 시 `is_shared = false`, `deck_shares` 레코드 삭제

### 3.2 특정 사용자 공유 관리 API

**`POST /api/decks/[id]/share/users`** - 사용자 추가

```typescript
// Request
{ user_id: string }

// Response 201
{ id: string, shared_with_id: string, display_name: string }
```

**`DELETE /api/decks/[id]/share/users/[userId]`** - 사용자 제거

```typescript
// Response 204 (No Content)
```

**`GET /api/decks/[id]/share/users`** - 공유 대상 목록

```typescript
// Response 200
{
  users: [
    { id: string, display_name: string, created_at: string }
  ]
}
```

- 최대 20명 제한
- 본인 덱의 share_mode = 'private'일 때만 동작

### 3.3 사용자 검색 API

**`GET /api/users/search?q={query}`**

```typescript
// Response 200
{
  users: UserSearchResult[]  // 최대 10명
}
```

- 인증 필수
- `display_name ILIKE '%query%'` 검색
- 이메일 부분 마스킹 반환 (프라이버시)
- 본인 제외
- 최소 2글자 이상 쿼리

### 3.4 덱 복제 (Clone) API

**`POST /api/decks/[id]/clone`**

```typescript
// Response 201
{
  deck_id: string,     // 새로 생성된 덱 ID
  card_count: number   // 복사된 카드 수
}
```

- 인증 필수
- 대상 덱: `share_mode = 'public'` 또는 `deck_shares`에 본인 포함
- 트랜잭션으로 처리: 덱 생성 → 카드 복사 (batch insert)
- 카드 수 제한: 500장 초과 시 에러
- 중복 import 방지: `source_deck_id` 로 체크
- 원본 `import_count` 증가 (RPC 호출)

**Vercel Best Practice 적용 (async-parallel)**:
```typescript
// 덱 정보 + 카드 목록 병렬 조회
const [deckRes, cardsRes] = await Promise.all([
  supabase.from("decks").select("*").eq("id", id).single(),
  supabase.from(cardTable).select("*").eq("deck_id", id),
]);
```

### 3.5 탐색 목록 API

**`GET /api/decks/explore?q={query}&type={type}&subject={subject}&sort={sort}&page={page}`**

```typescript
// Response 200
{
  decks: SharedDeckView[],
  total: number,
  page: number,
  pageSize: number
}
```

- 인증 필수
- `share_mode = 'public'`인 덱만 조회
- 정렬: `latest` (기본) / `cards` / `popular`
- 페이지네이션: 20개/페이지
- owner 정보: `profiles(display_name)` join

**Vercel Best Practice (server-serialization)**:
- SELECT 필요한 컬럼만 지정 (전체 `*` 대신)
- 카드 내용은 미리보기 API에서 별도 조회

### 3.6 공유 덱 미리보기 API

**`GET /api/decks/[id]/preview`**

```typescript
// Response 200
{
  deck: SharedDeckView,
  cards: PreviewCard[],  // 최대 10장
  already_imported: boolean
}

type PreviewCard = {
  word: string; meaning: string; phonetic?: string;  // vocab
} | {
  front_text: string; back_text: string;              // general
}
```

- 인증 필수
- 공유된 덱만 접근 가능
- `already_imported`: 현재 사용자가 이미 import했는지 체크

## 6. DB 마이그레이션

**파일**: `supabase/migrations/005_deck_sharing.sql`

```sql
-- 1. decks 테이블 컬럼 추가
ALTER TABLE decks ADD COLUMN IF NOT EXISTS share_mode TEXT DEFAULT 'none'
  CHECK (share_mode IN ('none', 'public', 'private'));
ALTER TABLE decks ADD COLUMN IF NOT EXISTS import_count INT DEFAULT 0;
ALTER TABLE decks ADD COLUMN IF NOT EXISTS source_deck_id UUID REFERENCES decks(id) ON DELETE SET NULL;
ALTER TABLE decks ADD COLUMN IF NOT EXISTS source_user_id UUID REFERENCES profiles(id) ON DELETE SET NULL;

-- is_shared와 share_mode 동기화: is_shared=true → share_mode='public'
UPDATE decks SET share_mode = 'public' WHERE is_shared = TRUE AND share_mode = 'none';

-- 2. deck_shares 테이블
CREATE TABLE IF NOT EXISTS deck_shares (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  deck_id UUID NOT NULL REFERENCES decks(id) ON DELETE CASCADE,
  owner_id UUID NOT NULL REFERENCES profiles(id) ON DELETE CASCADE,
  shared_with_id UUID NOT NULL REFERENCES profiles(id) ON DELETE CASCADE,
  created_at TIMESTAMPTZ DEFAULT now(),
  UNIQUE(deck_id, shared_with_id)
);

CREATE INDEX IF NOT EXISTS idx_deck_shares_shared_with ON deck_shares(shared_with_id);
CREATE INDEX IF NOT EXISTS idx_deck_shares_deck ON deck_shares(deck_id);

-- 3. RLS 정책
ALTER TABLE deck_shares ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Owner manages shares" ON deck_shares
  FOR ALL USING (owner_id = auth.uid());

CREATE POLICY "Shared user can view" ON deck_shares
  FOR SELECT USING (shared_with_id = auth.uid());

-- 4. 공유 덱 조회 정책 업데이트
DROP POLICY IF EXISTS "Shared decks are viewable" ON decks;

CREATE POLICY "Public shared decks viewable" ON decks
  FOR SELECT USING (
    auth.uid() IS NOT NULL AND share_mode = 'public'
  );

CREATE POLICY "Private shared decks viewable" ON decks
  FOR SELECT USING (
    auth.uid() IS NOT NULL AND share_mode = 'private'
    AND id IN (SELECT deck_id FROM deck_shares WHERE shared_with_id = auth.uid())
  );

-- 5. 탐색용 인덱스
CREATE INDEX IF NOT EXISTS idx_decks_share_mode ON decks(share_mode) WHERE share_mode = 'public';
CREATE INDEX IF NOT EXISTS idx_decks_import_count ON decks(import_count DESC) WHERE share_mode = 'public';
CREATE INDEX IF NOT EXISTS idx_decks_source ON decks(source_deck_id, user_id);

-- 6. 프로필 검색 인덱스
CREATE INDEX IF NOT EXISTS idx_profiles_display_name_trgm ON profiles
  USING gin(display_name gin_trgm_ops);

-- 7. import_count 증가 함수 (원자적)
CREATE OR REPLACE FUNCTION increment_import_count(deck_uuid UUID)
RETURNS void AS $$
BEGIN
  UPDATE decks SET import_count = import_count + 1 WHERE id = deck_uuid;
END;
$$ LANGUAGE plpgsql SECURITY DEFINER;
```
