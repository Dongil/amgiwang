## 1. 개요

암기왕 v2.5는 두 가지 핵심 목표를 달성한다:

1. **덱 공유 기능** - 서비스 가입 사용자 간 덱 공유. 전체 공유(탐색에 노출) 또는 특정 사용자 지정 공유. 검색으로 찾아서 내 덱으로 가져오기(import)
2. **UI 리디자인** - 하루종일 공부하는 학생의 눈에 편안한 디자인으로 전면 개선 (색상 팔레트, 네비게이션, 카드 UI)

### 디자인 레퍼런스
- **참고 앱**: 민트/에메랄드 그린 계열 학습앱 UI
- **핵심 특징**: 화이트 배경 + 그린 액센트, 넉넉한 여백, 큰 타이포그래피, 카드형 선택지, 둥근 모서리, 하단 CTA 버튼

## 2. 현재 상태 분석

### 2.1 공유 인프라 (이미 존재)
- `decks` 테이블: `share_id` (UNIQUE TEXT), `is_shared` (BOOLEAN) 필드 존재
- RLS: `is_shared = TRUE`인 덱은 모든 인증 사용자에게 SELECT 허용
- `cards`, `vocab_cards`: 공유 덱의 카드도 SELECT 허용
- 라우트: `/share/[shareId]` 페이지 파일 존재 (내용 미구현)
- 인덱스: `idx_decks_share_id`

### 2.2 현재 UI 문제점
- **색상**: 모노크롬(회색/검정) 팔레트 → 학습 동기부여 부족, 눈 피로
- **Primary 색상**: `oklch(0.205 0 0)` = 거의 검정 → 활기 없음
- **네비게이션**: 하단 4탭 (홈/덱/통계/설정) → 기본적이나 학습 흐름에 최적화되지 않음
- **타이포그래피**: 적절하나 제목/강조 구분이 약함
- **여백**: `p-4`, `gap-2` → 약간 빽빽함, 여유 부족
- **다크모드**: 지원되나 학생용으로 눈 편한 라이트모드가 우선

## 3. 기능 범위

### 3.1 덱 공유 (Feature A)

> **핵심 원칙**: 로그인한 서비스 사용자 간에만 공유. 비로그인 접근 불가.

#### A-1. 공유 모드 (2가지)

**전체 공유 (Public)**
- 모든 로그인 사용자가 탐색/검색으로 발견 가능
- 덱 상세 → "공유 설정" → "전체 공유" 선택
- 탐색 페이지(`/explore`)에 노출
- `decks.share_mode = 'public'`

**특정 사용자 공유 (Private)**
- 지정한 사용자 ID(이메일 또는 display_name)에게만 공유
- 덱 상세 → "공유 설정" → "특정 사용자" 선택 → 사용자 검색/추가
- 공유받은 사용자의 "공유받은 덱" 목록에 표시
- `deck_shares` 테이블로 관리 (초대 목록)

#### A-2. 공유 설정 UI
- 덱 상세 페이지에 "공유" 버튼 (Share 아이콘)
- 공유 다이얼로그:
  - 공유 모드 선택 (전체 / 특정 사용자 / 공유 안 함)
  - 전체 공유 시: ON/OFF 토글, 공유 중 아이콘 표시
  - 특정 사용자 시: 사용자 검색 입력 → 이메일/닉네임으로 검색 → 추가/제거
  - 현재 공유 대상 목록 표시
- 공유 중인 덱에 배지 표시 (덱 목록, 덱 상세)

#### A-3. 덱 탐색 & 검색 페이지
- `/explore` 라우트 (하단 네비 "탐색" 탭)
- **전체 공유 덱만** 노출 (로그인 필수)
- 검색: 제목, 과목, 덱 유형으로 검색
- 필터: 과목별, 덱 유형별 (영어단어 / 일반)
- 정렬: 최신순 / 카드 수순 / 인기순(import 횟수)
- 덱 카드에 제작자 닉네임, 카드 수, import 횟수 표시

#### A-4. 공유 덱 미리보기
- 탐색에서 덱 클릭 → 공유 덱 상세 보기
- 덱 정보: 제목, 설명, 카드 수, 덱 유형, 제작자
- 카드 미리보기 (처음 10장, 읽기 전용)
- "내 덱에 추가" 버튼

#### A-5. 덱 복제 (Import)
- "내 덱에 추가" 클릭 → 확인 다이얼로그
- 덱 + 모든 카드를 내 계정으로 복사 (새 deck_id 부여)
- 복사된 덱 제목에 "(공유)" 접미어 추가
- `source_deck_id`, `source_user_id` 메타데이터 저장
- 원본 덱의 `import_count` 증가
- 복제 완료 → 내 덱 상세 페이지로 이동
- 이미 import한 덱은 "이미 추가됨" 표시

#### A-6. 공유받은 덱 (특정 사용자 공유)
- 내 덱 목록에 "공유받은 덱" 섹션 또는 필터 탭
- 특정 사용자에게 공유받은 덱 목록 표시
- 공유받은 덱도 미리보기 → "내 덱에 추가" 가능
- 공유 취소 시 목록에서 자동 제거

#### B-2. 타이포그래피 개선
- 페이지 제목: `text-2xl font-bold` (현재 `text-lg`)
- 섹션 제목: `text-base font-semibold`
- 본문: `text-sm` 유지, 줄간격 `leading-relaxed`
- 카드 내 단어: `text-xl font-bold`

#### B-3. 여백 & 레이아웃
- 페이지 패딩: `p-4` → `p-5`
- 섹션 간격: `space-y-4` → `space-y-6`
- 카드 내부 패딩: `p-3~4` → `p-4~5`
- 버튼 높이: 최소 48px (터치 타겟)
- 카드형 선택지: 둥근 보더 `rounded-xl`, 선택 시 그린 보더 + 연한 그린 배경

#### B-4. 네비게이션 개선
- 하단 네비: 5탭으로 확장 → 홈 / 덱 / 탐색(공유) / 통계 / 설정
- 활성 탭: 그린 아이콘 + 그린 도트 인디케이터
- 페이지 헤더: 통일된 스타일 (뒤로가기 + 제목 + 액션)
- 페이지 전환: 부드러운 애니메이션 (선택사항)

#### B-5. 컴포넌트 스타일 업데이트
- **Button**: `rounded-xl`, 그린 primary, 그림자 제거 → 플랫 디자인
- **Card**: `rounded-2xl`, 미세한 보더, 섀도우 줄임
- **Badge**: 연한 배경 + 그린 텍스트
- **Input/Textarea**: `rounded-xl`, 두꺼운 보더 → 포커스 시 그린 링
- **Progress**: 그린 바
- **Toast**: 그린 계열 성공 토스트

#### B-6. 주요 화면별 개선

**대시보드 (홈)**
- 인사말 카드: "오늘도 힘내자!" 스타일 → 따뜻한 그린 그라데이션 배경
- 학습 현황: 카드형 디자인, 아이콘 강조
- 데일리 미션: 체크리스트 스타일, 완료 시 그린 체크

**덱 목록**
- 덱 카드: 좌측 컬러 바 → 전체 배경 그라데이션 (미세)
- 진행률 표시: 원형 프로그레스 또는 바 형태

**학습 뷰 (플래시카드)**
- 카드 넘기기: 부드러운 전환
- 정답/오답 피드백: 그린/레드 토스트 + 아이콘
- 타이머: 눈에 띄지 않는 위치

**퀴즈**
- 선택지: UI 샘플처럼 카드형 선택지, 선택 시 테두리 강조
- 결과 화면: 점수 원형 차트

## 5. DB 변경사항

### 5.1 기존 필드 활용
- `decks.share_id` (UNIQUE TEXT) - 이미 존재, 유지
- `decks.is_shared` (BOOLEAN) - 이미 존재, 유지 (전체 공유 플래그로 활용)

### 5.2 `decks` 테이블 컬럼 추가
```sql
-- 공유 모드: 'none' | 'public' | 'private'
ALTER TABLE decks ADD COLUMN IF NOT EXISTS share_mode TEXT DEFAULT 'none';
-- import 횟수 카운터
ALTER TABLE decks ADD COLUMN IF NOT EXISTS import_count INT DEFAULT 0;
-- 원본 덱 참조 (import된 덱에만)
ALTER TABLE decks ADD COLUMN IF NOT EXISTS source_deck_id UUID REFERENCES decks(id) ON DELETE SET NULL;
ALTER TABLE decks ADD COLUMN IF NOT EXISTS source_user_id UUID REFERENCES profiles(id) ON DELETE SET NULL;
```

### 5.3 새 테이블: `deck_shares` (특정 사용자 공유)
```sql
CREATE TABLE deck_shares (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  deck_id UUID NOT NULL REFERENCES decks(id) ON DELETE CASCADE,
  owner_id UUID NOT NULL REFERENCES profiles(id) ON DELETE CASCADE,
  shared_with_id UUID NOT NULL REFERENCES profiles(id) ON DELETE CASCADE,
  created_at TIMESTAMPTZ DEFAULT now(),
  UNIQUE(deck_id, shared_with_id)
);

CREATE INDEX idx_deck_shares_shared_with ON deck_shares(shared_with_id);
CREATE INDEX idx_deck_shares_deck ON deck_shares(deck_id);
```

### 5.4 RLS 정책 (로그인 사용자 전용)
```sql
-- 전체 공유 덱: 모든 인증 사용자가 조회 가능
DROP POLICY IF EXISTS "Shared decks are viewable" ON decks;
CREATE POLICY "Public shared decks are viewable" ON decks
  FOR SELECT USING (
    auth.uid() IS NOT NULL AND share_mode = 'public'
  );

-- 특정 사용자 공유 덱: 공유 대상자만 조회 가능
CREATE POLICY "Private shared decks are viewable" ON decks
  FOR SELECT USING (
    auth.uid() IS NOT NULL AND share_mode = 'private'
    AND id IN (SELECT deck_id FROM deck_shares WHERE shared_with_id = auth.uid())
  );

-- deck_shares 테이블 RLS
ALTER TABLE deck_shares ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Owner can manage shares" ON deck_shares
  FOR ALL USING (owner_id = auth.uid());
CREATE POLICY "Shared users can view" ON deck_shares
  FOR SELECT USING (shared_with_id = auth.uid());

-- 공유 덱의 카드 조회 (인증 사용자만)
-- cards, vocab_cards에 대해 공유 덱 참조 정책 유지 (기존 정책 활용)
```

### 5.5 사용자 검색용 인덱스
```sql
-- 닉네임/이메일 검색을 위한 인덱스
CREATE INDEX IF NOT EXISTS idx_profiles_display_name ON profiles(display_name);
```

## 9. 성공 기준

- [ ] 전체 공유: 탐색 페이지에서 검색 → 덱 발견 → 내 덱에 추가 가능
- [ ] 특정 사용자 공유: 닉네임/이메일 검색 → 공유 대상 지정 → 상대방 "공유받은 덱"에 표시
- [ ] 공유 덱 미리보기(카드 10장) + "내 덱에 추가" 동작
- [ ] 이미 import한 덱은 중복 추가 방지
- [ ] 전체 UI가 민트/에메랄드 그린 팔레트로 통일
- [ ] 10분 이상 학습 시 눈 피로감 감소 (주관적 테스트)
- [ ] 모바일 PWA에서 자연스러운 UX
- [ ] Lighthouse 접근성 점수 90+ 유지
- [ ] 빌드 에러 없음
