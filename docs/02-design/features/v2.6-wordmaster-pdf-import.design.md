## 3. PDF 파싱 엔진

### 3.1 아키텍처

```
src/lib/wordmaster/
├── parser.ts        # 메인 파서 (PDF → WordMasterEntry[])
├── types.ts         # 파싱 중간 타입
└── constants.ts     # 정규식, 상수
```

### 3.2 파싱 중간 타입 (types.ts)

```typescript
export interface WordMasterEntry {
  wordNumber: number;        // 0001~
  dayNumber: number;         // 1~30
  word: string;              // "evidence"
  meanings: ParsedMeaning[]; // 복수 품사/뜻
  exampleSentence: string;
  exampleTranslation: string;
  synonyms: ParsedRelated[];     // = 기호
  antonyms: ParsedRelated[];     // ↔ 기호
  collocations: ParsedCollocation[];  // + 기호 또는 인라인
  derivatives: ParsedRelated[];  // 탭 들여쓰기
}

export interface ParsedMeaning {
  pos: string;       // "n" | "v" | "a" | "ad"
  meaning: string;   // "증거, 흔적"
}

export interface ParsedRelated {
  word: string;      // "helpful"
  pos?: string;      // "a"
  meaning: string;   // "도움이 되는, 유익한"
}

export interface ParsedCollocation {
  phrase: string;    // "key ingredient"
  meaning: string;   // "핵심 성분"
  source?: string;   // "수능" | "교과서" | "학평" | "모평"
}
```

### 3.3 파싱 파이프라인 (parser.ts)

```
extractText(pdfBuffer)
  → splitByDay(fullText)       // DAY 경계 분할
  → splitByWord(dayText)       // 단어 번호 기준 분할
  → parseWordBlock(block)      // 각 단어 블록 파싱
  → WordMasterEntry[]
```

### 3.4 핵심 파싱 규칙

#### 3.4.1 DAY 경계 분할

```
패턴: "DAY\n{DD}" 또는 "DAY\n{D}"
분할: text.split(/DAY\n(\d{1,2})\n/)
결과: [dayNumber, dayText] 쌍
주의: DAY 18~20은 숙어(idiom) 구간, DAY 21~25는 어원 구간, DAY 26~30은 다의어/혼동어 구간
```

#### 3.4.2 단어 번호 + 단어 추출

```
패턴: /^(\d{4})\s*\n?([a-zA-Z][\w\s'-]*?)$/m
예: "0001 \nevidence\n" → { wordNumber: 1, word: "evidence" }
주의: 숙어 구간(DAY 18~20)은 "0681 \naccount for\n" 형태
```

#### 3.4.3 품사 + 뜻 추출

```
패턴: /^(n|v|a|ad)\s*(.+)$/
복수 품사: "n 증거, 흔적 v 입증하다" → split by 품사 경계
다의어(DAY 26~30): 번호+뜻 형태 "1. 비, 비율   2. 할당, 몫"
```

#### 3.4.4 유의어 (= 기호)

```
패턴: /^=\s+(.+?)\s+(n|v|a|ad)\s+(.+)$/
예: "= helpful a 도움이 되는, 유익한" → { word: "helpful", pos: "a", meaning: "도움이 되는, 유익한" }
복수 유의어: 같은 줄에 여러 개 "= explain v 설명하다  take up 차지하다"
```

#### 3.4.5 반의어 (↔ 기호 또는 공백+반의어)

```
패턴: /^[↔⇔]?\s*(.+?)\s+(n|v|a|ad)\s+(.+)$/
구분: 유의어(=) 바로 다음에 나오는, = 없는 관련어는 반의어
PDF 텍스트에서 ↔는 공백으로 추출됨 → 컨텍스트로 판단
```

#### 3.4.6 Collocation (+ 기호 또는 인라인 블록)

```
Type A (+ 기호):
  패턴: /^\+\s+(.+?)\s{2,}(.+)$/
  예: "+ good[clear/strong] evidence  훌륭한[명확한/강력한] 증거"

Type B (인라인 블록 - "~는 '...' 등의 어구로 자주 쓰인다"):
  패턴: 단어 반복 + 한국어 뜻 + 선택적 소스태그
  소스 태그: /\s+(수능|교과서|학평|모평)\s*$/
  예: "cognitive development 인지 발달 학평"
```

#### 3.4.7 파생어 (탭 들여쓰기)

```
패턴: /^\t(.+?)\s+(n|v|a|ad)\s+(.+)$/
예: "\tevident\ta\t분명한, 눈에 띄는"
→ { word: "evident", pos: "a", meaning: "분명한, 눈에 띄는" }
```

#### 3.4.8 DAY 구간별 특수 처리

| DAY 범위 | 유형 | 특수 처리 |
|----------|------|-----------|
| 01~17 | 일반 단어 | 표준 파싱 |
| 18~20 | 숙어 (idiom) | word에 구동사/숙어 저장, 파생어 없음 |
| 21~25 | 어원별 단어 | 어원 정보(`de(~로부터)+rive(작은 강)`) → `etymology_note`에 저장 |
| 26~30 | 다의어/혼동어 | 복수 뜻+예문 세트, meanings[]에 각 뜻별 매핑 |

## 4. API 설계

### 4.1 POST /api/wordmaster/parse

PDF 업로드 → 파싱 결과 반환 (임포트 전 미리보기용)

```typescript
// Request: multipart/form-data { file: PDF }
// Response:
{
  totalDays: 30,
  totalWords: 918,
  entries: WordMasterEntry[],  // 전체 파싱 결과
  sample: WordMasterEntry[],   // 처음 3개 미리보기
  errors: string[]              // 파싱 실패 항목
}
```

### 4.2 POST /api/wordmaster/import

파싱 결과 → DB INSERT

```typescript
// Request:
{
  entries: WordMasterEntry[],
  deckOption: "single" | "per-day",  // 단일 덱 vs DAY별 덱
  deckTitle?: string                  // 단일 덱일 때 제목
}

// Response:
{
  deckId: string,         // 단일 덱 ID (또는 첫 번째 덱)
  deckIds?: string[],     // DAY별 덱일 때 30개 ID
  importedCount: number,
  failedCount: number,
  errors: string[]
}
```

### 4.3 임포트 로직

```typescript
// 1. 덱 생성
const deck = await createDeck({
  deck_type: "english_vocab",
  title: deckTitle || "Word Master 고등 Complete",
  subject: "영어",
});

// 2. entries → vocab_cards 변환 + 배치 INSERT (50개씩)
for (const chunk of chunks(entries, 50)) {
  const cards = chunk.map(entry => ({
    deck_id: deck.id,
    word: entry.word,
    meaning: entry.meanings[0]?.meaning || "",
    meanings: entry.meanings.map(m => ({
      pos: m.pos,
      meaning: m.meaning,
      synonyms: entry.synonyms.filter(s => samePosGroup(s, m)).map(s => s.word),
    })),
    antonyms: entry.antonyms.map(a => ({ word: a.word, meaning: a.meaning })),
    derivatives: entry.derivatives.map(d => ({ word: d.word, meaning: d.meaning })),
    collocations: entry.collocations,
    example_sentence: entry.exampleSentence,
    example_translation: entry.exampleTranslation,
    word_number: entry.wordNumber,
    day_number: entry.dayNumber,
    source_book: "Word Master 고등 Complete",
    position: entry.wordNumber,
  }));
  await supabase.from("vocab_cards").insert(cards);
}

// 3. card_count 동기화
await supabase.rpc("sync_deck_card_count", { deck_id: deck.id });
```
